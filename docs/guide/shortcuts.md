# Keyboard shortcuts

| Keys | Action | Where |
| --- | --- | --- |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> … <kbd>Ctrl</kbd>+<kbd>7</kbd> | Sites, Model, Events, Calibrate, Explore, Compare, Assess | everywhere |
| <kbd>Ctrl</kbd>+<kbd>N</kbd>, <kbd>Ctrl</kbd>+<kbd>O</kbd>, <kbd>Ctrl</kbd>+<kbd>S</kbd> | New, open, save project | everywhere |
| <kbd>F5</kbd> | Run the page's main command | everywhere |
| <kbd>Shift</kbd>+<kbd>F5</kbd> | Stop what the page started | everywhere |
| <kbd>P</kbd>, <kbd>Z</kbd>, <kbd>F</kbd> | Pan, zoom box, fit all | charts and map |
| <kbd>C</kbd>, <kbd>V</kbd> | Select the calibration / validation period | Sites, Time series |
| <kbd>S</kbd> | Select tool | Sites, Map |
| <kbd>Alt</kbd>+click or drag | Pick zones only | Sites, Map |
| <kbd>Ctrl</kbd>+click | Add to or remove from the selection | Sites, Map |
| <kbd>Esc</kbd> | Clear the selection; leave a map tool; cancel a zone being drawn | Sites, Map |
| <kbd>Enter</kbd> | Finish the zone being drawn | Sites, Map |
| <kbd>←</kbd>, <kbd>→</kbd>, <kbd>Home</kbd> | Previous event, next event, whole record | Events |
| <kbd>1</kbd> … <kbd>4</kbd> | Hydrograph, UH shapes, Weights, Comparison | Events |
| <kbd>K</kbd> | Select the knee solution | Explore |

<kbd>Tab</kbd> moves through the controls of a page; every control has a name for screen readers.
